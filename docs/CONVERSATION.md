### Pulumi Neo (AI агент):
Принял задачу. Создаю:
1. Локальный AI-ассистент на базе Open WebUI + Ollama
2. Docker Compose (CPU и GPU варианты)
3. Linux установщик (install.sh)
4. Windows установщик (setup.ps1 + NSIS .exe)
5. Скрипты управления моделями
6. Полную документацию

**Техническое решение:**
- Open WebUI — веб-интерфейс (как ChatGPT, но локальный)
- Ollama — движок для AI моделей (работает без интернета)
- Docker Compose — упаковка всего в контейнеры
- NSIS — создание Windows .exe установщика
