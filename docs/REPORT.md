## 2. Использование токенов

### 2.1 Что такое токены в контексте AI

Токены — единица измерения текста для языковых моделей.  
Примерно: **1 токен ≈ 0.75 слова** (в английском), **1 токен ≈ 0.5 слова** (в русском).

### 2.2 Токены Pulumi Neo (этот сеанс)

Это — разговор с Pulumi Neo, который использует Anthropic Claude как языковую модель. Каждое обращение к агенту включает:

| Компонент | Описание |
|-----------|----------|
| Системный промпт | Инструкции агента (~5 000–8 000 токенов, отправляется каждый раз) |
| История разговора | Все предыдущие сообщения (растёт с каждым ходом) |
| Вывод инструментов | Результаты shell-команд, чтение файлов, API-ответы |
| Генерация ответа | Написанный код и текст |

**Оценка токенов за весь сеанс:**

| Тип | Примерное количество |
|-----|---------------------|
| Входящие токены (input) | ~400 000 – 600 000 |
| Исходящие токены (output) | ~80 000 – 120 000 |
| **Итого** | **~500 000 – 720 000 токенов** |

> Точное число недоступно агенту. Основные расходы: большой системный промпт (~6 000 токенов) × ~40 ходов разговора + вывод команд + сгенерированный код.

### 2.3 Стоимость токенов (Claude Sonnet 3.5, оценка)

| Тип | Цена | Итого |
|-----|------|-------|
| Input (~500 000 токенов) | $3 / 1M | ~$1.50 |
| Output (~100 000 токенов) | $15 / 1M | ~$1.50 |
| **Итого за сеанс** | | **~$3.00** |

> Pulumi Neo встроен в платформу Pulumi и использует внутреннюю квоту. Пользователю платить за токены напрямую не нужно — стоимость включена в подписку Pulumi.

### 2.4 Токены Pulumi Cloud (платформа)

Pulumi Neo как агентская платформа — это отдельный продукт от Pulumi.  
**Использование ресурсов Pulumi Cloud в этом проекте: 0 (ноль).**

Причина: Super Sistema — приложение на Docker Compose. Оно не использует:
- Pulumi стеки (stacks)
- Pulumi провайдеры (AWS, GCP, Azure и т.д.)
- Pulumi ESC (секреты)
- Pulumi Deployments

Весь код — чистые Docker/Shell/PowerShell/NSIS файлы без Pulumi IaC.

## 4. Итоги проекта

### Что реализовано
- Локальный AI-ассистент, не требующий интернета и облаков
- Поддержка всех популярных AI моделей через Ollama
- Автоматическая установка на Linux одной командой
- Графический установщик для Windows (.exe)
- Альтернативные установщики (batch, PowerShell)
- GitHub Actions для автосборки .exe при новых версиях
- Полная документация: технический, пользовательский, отчёт

### Известные ограничения
- AMD GPU не поддерживается (только NVIDIA и CPU)
- macOS поддерживается только через Docker (без нативного Metal GPU)
- .exe установщик не имеет кастомной иконки (используется системная)

### Возможные улучшения (следующая версия)
- Nginx reverse proxy с HTTPS
- Поддержка AMD GPU (ROCm)
- Systemd/Windows Service для автозапуска
- Кастомный логотип и иконка
