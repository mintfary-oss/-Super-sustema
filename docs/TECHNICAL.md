# Super Sistema — Техническая документация

**Версия:** 1.1.0  
**Дата:** Август 2026  
**Тип:** Локальный AI-ассистент

---

## 1. Обзор системы

Super Sistema — это автономная система для запуска AI-ассистентов на локальном оборудовании. Не требует подключения к облачным сервисам, интернета для работы после установки, платных API-ключей.

Основана на двух open-source проектах:
- **Ollama** — движок для локального запуска больших языковых моделей (LLM)
- **Open WebUI** — веб-интерфейс для общения с AI, совместимый с форматом ChatGPT

---

## 2. Что умеет приложение

### 2.1 Чат с AI
- Диалог с AI в реальном времени (потоковый вывод)
- Поддержка Markdown в ответах (код, таблицы, списки)
- История всех разговоров с поиском
- Создание, переименование, удаление чатов
- Экспорт истории в JSON/Markdown

### 2.2 Поддержка моделей
- Запуск любой модели из библиотеки Ollama (500+ моделей)
- Переключение между моделями внутри одного чата
- Одновременная загрузка нескольких моделей (при достаточном RAM)
- Загрузка и управление моделями прямо из интерфейса

| Категория          | Примеры моделей                                      |
|--------------------|------------------------------------------------------|
| Универсальные      | llama3.1, llama3.2, mistral, gemma2                  |
| Русский язык       | qwen2.5, llama3.1 (частично)                         |
| Программирование   | codellama, deepseek-coder, qwen2.5-coder             |
| Рассуждения        | deepseek-r1, phi4-reasoning                          |
| Компактные         | phi3:mini, llama3.2:1b (для слабых машин)            |
| Большие (GPU)      | llama3.1:70b, llama3.3:70b, deepseek-r1:70b          |

### 2.3 Работа с документами (RAG)
- Загрузка PDF, DOCX, TXT, MD файлов в чат
- Встроенный векторный поиск по документам
- Вопросы по содержимому загруженных файлов
- Постоянные коллекции документов (Knowledge Base)

### 2.4 Работа с изображениями (Vision)
- Анализ изображений (JPG, PNG, WebP)
- Описание содержимого фото
- Сравнение изображений
- Работает с мультимодальными моделями: llava, bakllava, moondream

### 2.5 Генерация изображений (опционально)
- Интеграция с AUTOMATIC1111 / ComfyUI (если установлены)
- Генерация по текстовому описанию прямо в чате
- Модели Stable Diffusion, FLUX

### 2.6 Голосовой ввод и вывод
- Распознавание голоса через браузерный микрофон (Web Speech API)
- Синтез речи для ответов AI (TTS)
- Выбор голоса и скорости воспроизведения

### 2.7 Управление пользователями
- Многопользовательский режим (при `WEBUI_AUTH=true`)
- Роли: Администратор, Пользователь, Только чтение
- Персональные настройки для каждого пользователя
- Общие и личные коллекции документов

### 2.8 Системные промпты и персонажи
- Создание собственных AI-персонажей с заданным характером
- Системные инструкции (system prompt) для каждого чата
- Библиотека готовых промптов (prompt library)
- Импорт персонажей в формате CharacterCard

### 2.9 Подключение внешних API (опционально)
- OpenAI API (GPT-4, GPT-3.5) — если есть ключ
- Anthropic API (Claude) — если есть ключ
- Любой OpenAI-совместимый API (Groq, Together, LM Studio и др.)
- Одновременная работа и с локальными, и с облачными моделями

### 2.10 Инструменты и функции (Functions/Tools)
- Веб-поиск (с подключением поисковых API)
- Выполнение Python кода в изолированной среде
- Вызов внешних API через webhook
- Собственные инструменты через плагины

## 3. Архитектура

```
[Пользователь: браузер]
        │  HTTP :3000
        ▼
┌───────────────────┐
│    Open WebUI     │  ← веб-сервер, UI, авторизация
│  (Python/FastAPI) │    хранение чатов, документов, настроек
└────────┬──────────┘
         │  HTTP :11434
         ▼
┌───────────────────┐
│      Ollama       │  ← движок моделей
│   (Go binary)     │    загрузка/выгрузка моделей в память
└────────┬──────────┘
         │  mmap / CUDA / Metal
         ▼
┌───────────────────┐
│   AI Модели       │  ← файлы .gguf на диске
│  (GGUF формат)    │    квантизованные веса нейросети
└───────────────────┘
```

### 3.1 Хранение данных

| Данные                  | Расположение                          |
|-------------------------|---------------------------------------|
| AI модели               | Docker volume `super-sistema-ollama-data` |
| Чаты, документы, настройки | Docker volume `super-sistema-webui-data`  |
| Конфигурация            | Файл `.env` в директории установки    |

### 3.2 Сетевая топология

| Компонент   | Порт  | Доступ              |
|-------------|-------|---------------------|
| Open WebUI  | 3000  | Внешний (браузер)   |
| Ollama API  | 11434 | Только внутри Docker |
| GPU Panel   | 8765  | Внешний (Tesla P100 кнопка) |

### 3.3 GPU Panel — Tesla P100 (порт 8765)

```
[Браузер: http://localhost:8765]
        │  HTTP :8765
        ▼
┌───────────────────────┐
│  gpu-panel (FastAPI)  │  ← SSE потоки статуса GPU
│  app.py               │    POST /api/activate → trigger файл
└──────────┬────────────┘
           │  bind mount /tmp/super-sistema/shared
           ▼
┌───────────────────────┐
│  watch-gpu.sh (хост)  │  ← читает trigger файл
│  setup-tesla-p100.sh  │    пишет прогресс в progress.log
└───────────────────────┘
```

API endpoints GPU Panel:

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/` | GET | HTML панель с кнопкой и мониторингом |
| `/api/status` | GET | JSON: статус GPU, Ollama, PCIe |
| `/api/activate` | POST | Нажатие кнопки → создаёт trigger файл |
| `/api/progress?since=N` | GET | Строки прогресса установки |
| `/stream/gpu` | GET SSE | Статус GPU каждые 3 сек |
| `/stream/progress` | GET SSE | Прогресс установки в реальном времени |

## 6. Конфигурация (.env параметры)

| Параметр                  | По умолчанию                        | Описание                              |
|---------------------------|-------------------------------------|---------------------------------------|
| `WEBUI_SECRET_KEY`        | (генерируется при установке)        | Ключ шифрования сессий                |
| `WEBUI_PORT`              | `3000`                              | Порт веб-интерфейса                   |
| `WEBUI_AUTH`              | `false`                             | Требовать авторизацию (true/false)    |
| `OLLAMA_KEEP_ALIVE`       | `24h`                               | Время хранения модели в памяти        |
| `OLLAMA_NUM_PARALLEL`     | `1`                                 | Параллельных запросов (1 для CPU)     |
| `OLLAMA_MAX_LOADED_MODELS`| `1`                                 | Моделей одновременно в памяти         |
| `DEFAULT_MODELS`          | `llama3.2:3b`                       | Модель по умолчанию                   |

## 7. API

Ollama предоставляет REST API на порту 11434 (доступен локально):

```bash
# Список установленных моделей
curl http://localhost:11434/api/tags

# Генерация текста
curl http://localhost:11434/api/generate -d '{
  "model": "llama3.2:3b",
  "prompt": "Привет! Как дела?"
}'

# OpenAI-совместимый endpoint
curl http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "llama3.2:3b",
    "messages": [{"role": "user", "content": "Привет"}]
  }'
```

Open WebUI API доступен на порту 3000 (документация: http://localhost:3000/docs).

## 8. Безопасность

- Все данные хранятся локально, ничего не передаётся в интернет
- При `WEBUI_AUTH=false` — доступ без пароля (только для домашней сети)
- При `WEBUI_AUTH=true` — требуется регистрация, первый пользователь становится администратором
- Рекомендуется поставить nginx reverse proxy с HTTPS для доступа из интернета
- Ollama API (11434) не открыт наружу — только внутри Docker-сети

## 10. Резервное копирование

```bash

  -v $(pwd):/backup alpine \
  tar czf /backup/webui-backup-$(date +%Y%m%d).tar.gz /data

docker run --rm -v super-sistema-ollama-data:/data \
  -v $(pwd):/backup alpine \
  tar czf /backup/ollama-backup-$(date +%Y%m%d).tar.gz /data

# Восстановление
docker run --rm -v super-sistema-webui-data:/data \
  -v $(pwd):/backup alpine \
  tar xzf /backup/webui-backup-YYYYMMDD.tar.gz -C /
```
