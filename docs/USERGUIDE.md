# Super Sistema — Руководство пользователя

**Версия:** 1.1.0

---

## Шаг 1: Установка

### Windows

1. Убедитесь что **Docker Desktop** запущен (значок кита в трее)
2. Скачайте **SuperSistema-Setup.exe** с [GitHub Releases](https://github.com/mintfary-oss/-Super-sustema/releases)
3. Кликните правой кнопкой → **"Запуск от имени администратора"**
4. Следуйте инструкциям установщика
5. После установки откройте браузер: **http://localhost:3000**

Если нет Docker Desktop — установщик сам откроет страницу загрузки.

### Linux

```bash
git clone https://github.com/mintfary-oss/-Super-sustema.git super-sistema
cd super-sistema
bash install.sh
```

> **Важно:** обязательно указывайте `super-sistema` в конце команды clone.
> Без этого папка создаётся как `-Super-sustema`, и `cd` в неё не работает
> (bash воспринимает `-S` как флаг).

Скрипт сам установит Docker если его нет, скачает образы и запустит систему.

### Tesla P100 / NVIDIA GPU (опционально)

```bash
git clone https://github.com/mintfary-oss/-Super-sustema.git super-sistema
cd super-sistema
bash install.sh                                        # базовая установка
docker compose -f docker-compose.gpu.yml up -d        # запуск с GPU
```

Открыть GPU панель: **http://localhost:8765** → нажать **ВКЛЮЧИТЬ TESLA P100**

Скрипт сам найдёт карту, установит NVIDIA драйверы, настроит монитор (iGPU остаётся основным) и запустит Ollama с GPU.

## Шаг 2: Первый запуск

1. Откройте браузер и перейдите на **http://localhost:3000**
2. Вы увидите интерфейс чата — он уже готов к работе
3. В верхнем меню выберите модель (по умолчанию `llama3.2:3b`)
4. Введите вопрос в поле внизу и нажмите Enter

> Первый ответ может быть медленным — модель загружается в память. Последующие ответы быстрее.

---

## Шаг 3: Скачать дополнительные модели

### Через интерфейс
1. Нажмите на иконку профиля (правый верхний угол)
2. Перейдите в **Settings → Models**
3. В поле "Pull a model" введите название модели (например `mistral:7b`)
4. Нажмите кнопку загрузки

### Через скрипт (рекомендуется)
```bash
bash scripts/download-models.sh
```
Появится меню с готовыми наборами моделей.

### Вручную
```bash
docker exec super-sistema-ollama ollama pull qwen2.5:7b
```

## Использование чата

### Основные действия

| Действие | Как сделать |
|----------|-------------|
| Новый чат | Кнопка "New Chat" (левая панель) |
| Выбрать модель | Выпадающий список вверху чата |
| Загрузить файл | Кнопка скрепки рядом с полем ввода |
| Голосовой ввод | Кнопка микрофона в поле ввода |
| Копировать ответ | Кнопка копирования под ответом AI |
| Редактировать запрос | Кнопка карандаша рядом с вашим сообщением |
| Регенерировать ответ | Кнопка обновления под ответом AI |

### Форматирование запросов

Система понимает обычный текст. Для лучших результатов:

```
Плохо:  "код"
Хорошо: "Напиши Python функцию для сортировки списка словарей по ключу 'name'"

Плохо:  "переведи"  
Хорошо: "Переведи следующий текст с английского на русский, сохраняя деловой стиль:"
```

### Системный промпт (роль AI)
1. Нажмите кнопку "+" рядом с полем ввода → **System Prompt**
2. Задайте роль: `Ты опытный Python разработчик. Отвечай кратко и только с примерами кода.`

## Работа с документами

### Загрузить документ в чат
1. Нажмите кнопку **скрепки** (📎) рядом с полем ввода
2. Выберите файл (PDF, DOCX, TXT, MD)
3. Спрашивайте: `"Какие ключевые выводы в этом документе?"`

### Постоянная база знаний
1. Левая панель → **Workspace → Knowledge**
2. Кнопка "+" → создать коллекцию
3. Загрузите документы в коллекцию
4. В чате: нажмите "#" и выберите коллекцию

### Важные параметры

| Раздел | Параметр | Описание |
|--------|----------|----------|
| General | Language | Язык интерфейса |

## Управление системой

### Команды (Linux)

```bash
# Запустить
docker compose up -d

# Остановить
docker compose down

# Перезапустить
docker compose restart

# Посмотреть логи
docker compose logs -f

# Статус контейнеров
docker compose ps

# Обновить
bash scripts/update.sh
```

### Команды (Windows — PowerShell или cmd)

```powershell
# Перейдите в папку установки
cd "C:\super-sistema"   # или куда установили

# Запустить
docker compose up -d

# Остановить  
docker compose down

# Логи
docker compose logs -f
```

## Решение частых проблем

### Интерфейс не открывается
```bash
# Проверить статус
docker compose ps

# Если контейнер не запущен
docker compose up -d

# Проверить логи
docker compose logs open-webui
```

### Модель отвечает очень медленно
- Используйте меньшую модель: `phi3:mini` (2.3 GB) или `llama3.2:3b` (2 GB)
- Закройте другие программы чтобы освободить RAM
- На CPU скорость 2–8 токенов/сек — это нормально

### Ошибка "out of memory"
- Выбранная модель слишком большая для вашего RAM
- Попробуйте меньшую модель или закройте другие приложения

### Порт 3000 занят
```bash
# Изменить порт в .env
echo "WEBUI_PORT=3001" >> .env
docker compose up -d
# Открыть: http://localhost:3001
```

### Сбросить все данные
```bash
docker compose down
docker volume rm super-sistema-webui-data
docker compose up -d
```

## Безопасность

- Не открывайте порт 3000 в интернет без пароля
- Для домашней сети: `WEBUI_AUTH=false` — всё нормально
- Для офиса или сервера: установите `WEBUI_AUTH=true` в `.env` и перезапустите

## Удаление

**Linux:**
```bash
bash uninstall.sh
```

**Windows:**
```
Пуск → Параметры → Приложения → Super Sistema → Удалить
```

Все данные (модели, чаты) сохраняются — вас спросят отдельно.
