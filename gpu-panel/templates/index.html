💡 Решение проблемы с монитором

Проблема: При включении Tesla P100 монитор гаснет.

Причина: Tesla P100 не имеет видеовыходов — это вычислительная карта.

Решение: В BIOS установите:
Primary Display → IGFX
(или Integrated Graphics / CPU Graphics)

После этого:
  • Монитор всегда работает через процессор
  • Tesla P100 используется только для AI/вычислений
  • Можно подключать P100 без перезагрузки
